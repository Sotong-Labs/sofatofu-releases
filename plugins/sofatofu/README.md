# sofatofu

**You had the call. Your agent can log it.**

sofatofu is a CRM built for agents. Ask yours to find a contact, log a call, update a deal, or review your pipeline. It can also add and delete records, manage members, and change workspace settings.

Before each change, your agent reads the current data and gives a reason. You can see what changed and why, and undo most changes.

This plugin connects your agent to sofatofu at `https://sofatofu.com/mcp` and includes the sofatofu skill, a guide to working with your CRM. Each connection works in one workspace, which you choose when you approve access. Your agent can do only what your role allows.

## Install in Claude Code

```text
/plugin marketplace add Sotong-Labs/sofatofu-releases
/plugin install sofatofu@sofatofu
```

## Install in Codex

```sh
codex plugin marketplace add Sotong-Labs/sofatofu-releases
codex plugin add sofatofu@sofatofu
```

To connect, sign in to sofatofu in the browser, choose a workspace, and approve the connection. In Claude Code, run `/mcp` and select sofatofu to start the sign-in.
