# sofatofu

sofatofu is a CRM built for agents. This repository holds the release files of the `sofatofu` CLI and the sofatofu plugin for Claude Code and Codex.

## Documentation

Start with the sofatofu skill, the guide that agents read to work with sofatofu: <https://sofatofu.com/skills/sofatofu/SKILL>

To set up the CLI, the connector, or the plugin, read the [setup guide](https://sofatofu.com/skills/sofatofu/references/setup).

This repository holds a copy of the same skill in [`plugins/sofatofu/skills/sofatofu`](plugins/sofatofu/skills/sofatofu/SKILL.md).
